# DOC-FAQ: 솔빛서비스 공개 FAQ

학습용 가상 문서. 실제 제품 정책이나 약속이 아니다.

- 버전: 2.0
- 시행일: 2026-10-01
- 상태: approved
- 소유자: 고객지원 문서 담당
- 읽기 범위: support, public
- 공개 등급: public

## 로그인

비밀번호를 잊었다면 로그인 화면의 비밀번호 재설정 기능을 사용한다. 계정 소유자 변경과 재설정 메일 미수신은 고객지원 담당자가 확인한다. 이 FAQ는 신원 확인을 생략하거나 계정을 직접 변경할 권한을 제공하지 않는다.

## 알림

제품 버전 3에서는 설정의 알림 메뉴에서 일반 알림을 켜거나 끌 수 있다. 다른 버전의 메뉴 위치는 이 문서에 없다. 보안 알림은 일반 알림과 다르며 이 문서로 해제 여부를 안내할 수 없다.

## 자료 내보내기

제품 버전 3의 관리자 역할은 보고서 화면에서 CSV 내보내기를 요청할 수 있다. 결과는 현재 사용자가 접근 가능한 보고서 범위로 제한된다. 일반 사용자 권한과 제품 버전이 확인되지 않으면 추가 정보를 요청한다.

## 문의 접수

고객지원 문의에는 제품 버전, 발생 시각과 오류 메시지를 기입한다. 비밀번호, API 키와 불필요한 개인정보는 보내지 않는다. 첨부 파일을 보내기 전 비밀 정보를 제거한다.

학습용 가상 문서. 실제 보안 구성·주소·비밀 값이 들어 있지 않다.

## 내부 점검

내부 보안 알림의 설정과 점검은 보안 담당자가 승인된 운영 경로에서 수행한다. 고객에게 내부 점검 절차를 전달하거나 알림을 해제할 지침으로 사용하지 않는다.

실제 운영 정보와 비밀은 별도 승인된 저장소에서 관리한다. 이 문서가 검색되더라도 고객용 초안의 공개 근거로 사용하지 않는다.

# 비용과 효과 계산표

단위는 건/월, 분/건, 원, 원/시간으로 통일한다. 가정·관측·검증 결과를 각 행에 표시한다. 이 양식의 기본 예시는 모두 계획 가정이다.

| 변수 | 가상 기본값 | 독자 값 | 근거·구분 |
| --- | --- | --- | --- |
| 월 전체 건수 V | 2400 |  | 가정 |
| 적격 비율 E | 0.8 |  | 가정 |
| 적격 중 적용률 A | 0.75 |  | 가정 |
| 기존 시간 B | 10분 |  | 검토·재작업 포함 범위 명시 |
| 적용 후 시간 N | 6분 |  | 검토 포함 가정 |
| 시간당 가치 W | 25000원 |  | 가치 평가, 현금 아님 |
| 초기 현금비 S | 6000000원 |  | 가정 |
| 비교 배분 기간 M | 12개월 |  | 계획 비교, 회계 처리 아님 |
| 반복 현금비 C | 900000원/월 |  | 가정 |
| 내부 운영 시간 가치 I | 500000원/월 |  | 현금비와 중복 금지 |
| 현금화 비율 R | 0.25 |  | 미확인 시 0으로 계산 |

```text
유효 적용 건수 = V × E × A
월 시간 변화 H = 유효 적용 건수 × (B − N) / 60
잠재 시간 가치 P = H × W
월 경제적 부담 = S / M + C + I
월 경제적 차이 = P − 월 경제적 부담
월 현금 변화 F = P × R − C
단순 초기 현금 회수 기간 = S / F (F > 0일 때만)
```

기본값 결과: 1440건, 96시간, 잠재 가치 240만원, 경제적 부담 190만원, 경제적 차이 50만원, 월 현금 변화 -30만원. 양의 회수 기간이 없다. 현금 비교에는 초기비를 별도로 회수하므로 월 배분액을 다시 빼지 않는다. 내부 운영비가 실제 추가 지급이라면 그 금액을 반복 현금비에 반영하고 중복 계산하지 않는다.

실제 적용 건수를 직접 측정한 경우 V×E×A 대신 그 건수를 사용한다. 처리 후 시간이 더 길면 음수 변화도 그대로 기록한다. 이 간단한 비교는 세금·금융비용·할인·물량 증가·수익 변화를 모델링하지 않는다.

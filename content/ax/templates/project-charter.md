# AX 파일럿 기획서

파일럿은 중요한 가정을 제한된 범위에서 확인하는 실험이다. 아래 항목은 저자 제안이며 조직의 필수 검토를 대신하지 않는다.

- 과제 ID / 작성일 / 버전:
- 업무 소유자 / 기술 소유자 / 사용자 대표:
- 문제 정의서와 준비도:

| 항목 | 작성할 내용 |
| --- | --- |
| 가설 | 대상 업무·변경 단계·기대 결과 |
| 비교 | 기존 흐름 또는 자료 정비만 적용한 흐름 |
| 대상 | 사용자·문의 유형·자료·기간 |
| 제외 | 금전·권한 변경·외부 발송 등 범위 밖 행동 |
| AI 역할 | 검색·초안·허용 도구 |
| 사람 역할 | 근거·공개 범위·판단·승인 |
| 기준선 | 정의·표본·수집 책임 |
| 평가 | 정상·예외·권한·공격 사례와 기준 |
| 비용 | 초기·반복·내부 시간·사용 제한 |
| 대체 | 장애·보류 시 기존 처리 경로 |
| 중단 | 사건·영향·중단 권한자 |
| 다음 결정 | 유지·수정·중단·확대 조건 |

## 시작 전에 필요한 증거

자료 승인, 권한 설계, 필요한 처리 조건 검토, 평가 계획, 사용자 교육과 복귀 경로를 확인한다. 미완료 항목에는 담당자와 기한을 적고 진행 가능한 범위를 제한한다.

## 실험 후 기록

- 관측 결과 / 제외·실행 오류 / 표본의 한계:
- 비용·품질·검토 부담:
- 가정이 틀린 부분과 개선:
- 결정자·결정일·후속 담당자:

솔빛서비스 예시의 첫 범위는 승인 공개 자료 검색과 초안이며, 사람이 검토하고 기존 화면에서 발송한다. 다른 도구의 추가는 이 기획서의 변경과 재검토가 필요하다.

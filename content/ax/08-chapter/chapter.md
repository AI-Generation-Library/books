# 08장. 비용과 기대 효과 계산하기

“한 건에 4분을 줄일 수 있다”는 계산은 좋은 출발점이지만 예산 결정을 끝내지는 못한다. 모든 업무에 적용할 수 있는지, 실제로 사용하는 비율은 얼마인지, 검토와 재작업까지 포함했는지 확인해야 한다. 줄인 시간이 현금 지출 감소로 이어지는지도 별도의 질문이다.

이 장의 숫자는 전부 **가상 계획 가정**이다. 특정 모델의 가격이나 실제 기업의 효과를 나타내지 않는다. 실제 도입에서는 현재 계약과 측정 결과로 값을 교체하고 재무 담당자와 비용의 분류를 확인한다.

## 1. 먼저 기준선을 정의하기

현재 업무의 처리 시간에는 자료 검색, 작성, 검토와 재작업이 들어간다. 고객이 기다리는 시간도 중요하지만 담당자의 실제 작업 시간과 구분한다. AI 적용 후의 시간에도 결과 확인과 오류 처리 시간을 포함한다. 작성 시간만 줄어든 것을 전체 처리 시간 감소로 계산하면 효과를 과장한다.

단순 문의와 복잡한 문의를 나누고, 측정 대상의 분포를 기록한다. 기준선은 평균 하나로 끝내기보다 중앙값, 긴 처리의 발생과 예외 유형도 함께 본다. 이 장의 간단한 계산은 계획을 비교하는 예시이며, 실제 평가 설계는 27장에서 다룬다.

## 2. 적용 가능성과 실제 사용을 분리하기

솔빛서비스의 계획 가정을 다음과 같이 둔다.

| 항목 | 가정 |
| --- | ---: |
| 월 전체 업무량 | 2,400건 |
| 기존 건당 작업 시간 | 10분 |
| 적용 후 건당 작업 시간, 검토 포함 | 6분 |
| 적용 가능한 비율 | 80% |
| 적용 가능 업무 중 실제 사용 비율 | 75% |
| 시간 가치 산정에 사용하는 시간당 비용 | 25,000원 |

적용 가능 업무는 2,400 × 0.8 = 1,920건이다. 이 중 실제 사용을 가정한 업무는 1,920 × 0.75 = 1,440건이다. 건당 4분을 줄인다면 월 5,760분, 즉 **96시간**의 작업 여유를 기대하는 계산이 된다.

```text
적용 업무량 = 전체 업무량 × 적용 가능 비율 × 실제 사용 비율
시간 변화 = 적용 업무량 × (기존 시간 - 적용 후 시간) ÷ 60
잠재 시간 가치 = 시간 변화 × 시간당 가치
```

이 예시의 잠재 시간 가치는 96 × 25,000 = **240만 원**이다. 이는 측정된 절감액이 아니다. 해당 시간이 다른 업무에 유용하게 쓰일 수 있다는 계획상의 평가이며, 급여나 지출이 자동으로 줄어든다는 의미도 아니다.

이미 실제 적용 건수를 측정했다면 적용 가능 비율과 사용 비율을 다시 곱해 이중으로 줄이지 않는다. 계획 가정과 관측 값을 섞을 때는 각 값의 모집단과 의미를 먼저 확인한다.

## 3. 총비용에 무엇을 포함할 것인가

비용에는 도구·API 이용료 외에도 자료 정비, 연결 개발, 보안 검토, 교육, 평가, 지원과 운영 시간이 들어간다. 모델 호출 수가 적어도 결과를 검토하는 부담이 크면 전체 비용은 커질 수 있다.

다음 가정으로 월별 경제적 부담을 비교해 본다.

| 항목 | 가정 | 계산에서의 의미 |
| --- | ---: | --- |
| 초기 현금 투입 | 600만 원 | 시작 시점의 현금 흐름 |
| 초기 비용 비교 기간 | 12개월 | 계획 비교를 위한 분산 가정 |
| 월 반복 현금 비용 | 90만 원 | 도구·운영 계약 등 |
| 월 내부 운영 시간 가치 | 50만 원 | 기존 인력의 운영 부담 |

초기 투입을 12개월에 나누면 월 50만 원이다. 이를 반복 현금 비용 90만 원, 내부 운영 부담 50만 원과 합하면 월 **190만 원**의 경제적 부담을 비교하는 계산이 된다. 잠재 시간 가치 240만 원과의 차이는 월 **50만 원**이다. 이 방식은 가정 비교를 위한 것이며 회계상 비용 처리나 세무 판단을 대신하지 않는다.

초기 현금을 이렇게 나누어 비교해도 실제 현금이 매월 50만 원씩 나가는 것은 아니다. 초기 지출과 매월 지출을 구분해야 현금 흐름과 회수 가능성을 이해할 수 있다.

## 4. 시간 가치와 현금 효과를 따로 보기

기존 인력의 급여가 그대로라면 시간을 줄였다는 이유만으로 그 급여가 현금 절감이 되지는 않는다. 확보한 여유를 대기 감소, 품질 검토나 다른 업무에 사용한다면 그 가치를 별도로 관찰한다. 외주 지출이나 추가 근무 비용이 실제로 줄어드는지 확인할 수 있을 때 현금 효과를 기록한다.

가상의 비교를 위해 잠재 시간 가치 중 25%가 실제 지출 감소로 연결된다고 가정하면 월 60만 원이다. 반복 현금 비용 90만 원과 비교한 월 현금 변화는 **-30만 원**이다. 경제적 시간 가치의 비교가 양수라고 해서 현금 회수도 가능하다는 결론이 나오지 않는다. 이 가정에서는 초기 600만 원의 단순 현금 회수 기간을 계산할 수 없다.

현금으로 연결되는 비율을 모른다면 0으로 두고 별도 검증 대상으로 남기는 것이 낫다. 계획서에는 현금 효과, 시간 여유, 품질과 고객 경험을 구분해 적는다. 같은 효과를 두 항목에서 중복으로 더하지 않는다.

## 5. 민감도와 나쁜 시나리오

실제 사용 비율을 바꾸면 같은 기술적 시간 절감도 다른 결과를 만든다. 다른 가정은 유지한 예시다.

| 사용 비율 | 월 시간 변화 | 잠재 시간 가치 | 190만 원 대비 차이 |
| --- | ---: | ---: | ---: |
| 50% | 64시간 | 160만 원 | -30만 원 |
| 75% | 96시간 | 240만 원 | 50만 원 |
| 100% | 128시간 | 320만 원 | 130만 원 |

사용 비율뿐 아니라 검토 시간이 늘어나거나 운영 비용이 증가하는 경우도 계산한다. 적용 후 시간이 더 길어진다면 음수 결과를 그대로 기록해야 한다. 효과를 0으로 잘라 표현하면 악화된 업무가 숨는다.

가격과 호출량은 실제 제공자의 최신 계약 조건으로 확인한다. 개발·평가·재시도에 사용한 호출, 로그 저장과 자료 갱신 비용도 포함한다. 이 책의 계산 예제는 AI API를 호출하지 않는 일반 Python 프로그램이다.

## 점검 질문과 정리

- 적용 대상과 실제 사용을 이중으로 계산하지 않았는가?
- 절약한 시간을 현금 절감으로 바로 기록하지 않았는가?
- 불리한 가정에서도 운영할 이유와 중단할 조건을 설명할 수 있는가?

좋은 비용 계산은 낙관적인 숫자를 만드는 것이 아니라 중요한 가정을 드러낸다. 다음 장에서는 그 가정을 파일럿의 확인 과제로 바꾼다.

# 작성 기록과 실제 검증 범위

기준일: 2026-10-13. 이 책은 AI 작성 초안이며 전체 사람 검수·전문가 검수를 완료하지 않았다.

## 작성과 패키징

사용자가 승인한 《AX 완전 정복》 7부·30장 목차를 고정해 이 대화에서 Codex가 집필했다. 생성기의 `package` 명령은 외부 원고를 파일·메타데이터·목차·ZIP으로 정리했다. 이후 실제 검사 기록과 독서 안내·자료의 frontmatter를 보완해 최종 ZIP을 만들었다.

- 작성 도구: Codex. 정확한 모델 식별자는 확인되지 않아 `null`로 기록.
- 생성기 제공자 경로: `external-manuscript`.
- 생성기의 별도 OpenAI·Claude·Gemini API 호출: 없음. 체크포인트의 API 호출 목록은 빈 배열.
- 생성기의 API 토큰 카운터 0은 이 패키징 작업의 호출 기준이다. Codex 대화 사용량이 0이라는 뜻이 아니다.
- 승인 목차: [approved-plan.json](../approved-plan.json).
- 작성 입력·출처: [generation-input.json](../generation-input.json).

## 실제 수행한 검사

1. 승인한 30개 장 제목·순서·7개 파트 범위와 원고 파일·frontmatter 번호를 대조했다.
2. Markdown 코드 블록의 닫힘과 책 내부 링크의 파일 존재·경계, 메타데이터와 ZIP 구성을 검사했다.
3. Python 로컬 예제 테스트 10개를 실행해 통과했다. 기본 비용 산술, 음수 시간 변화, 현금화 미확인, 입력 오류와 가상 자료의 ID·분류·참조를 확인했다.
4. 기본 계산기를 실제 실행해 1440건·96시간·잠재 가치 240만원·월 경제적 차이 50만원·월 현금 변화 -30만원을 확인했다. 양의 단순 회수 기간은 없다.
5. [참고 자료](references.md)의 공식 페이지와 지정한 법령 조문을 확인했다. 첨부 PDF 전문이나 시행령·모든 분야별 규정을 검토했다고 표시하지 않았다.

실습 실행 명령은 [예제 안내](../examples/README.md)에 있다. 전체 책 형식 검사와 공개 서비스의 빌드·배포 결과는 저장소의 Actions 실행 기록에서 확인할 수 있다. 이 기록은 배포 성공을 사업 성과로 해석하지 않는다.

## 확인하지 않은 것

가상의 회사·수치·문서·24개 평가 사례는 실제 조사 자료가 아니다. 모든 모델 평가 사례는 `not-run`이며 답변 성능·정확도·안전성 점수를 산출하지 않았다. 실제 기업 적용·고객 데이터·현금 효과를 검증하지 않았다. 법적 적용·전문가 검수·전체 사람 편집은 미수행이다.

## ZIP과 라이선스

다운로드 ZIP에는 원고·메타데이터·승인 목차·작성 입력·13종 양식·실습·라이선스가 들어 있다. 자기 자신을 포함하는 순환을 피하기 위해 ZIP 안의 `book.json.downloads`는 빈 배열이며, 공개 사이트의 메타데이터에만 ZIP 경로를 등록한다. 원고 내용은 동일하다.

원고와 저자 작성 실습은 books 저장소의 CC0 정책으로 배포한다. 외부 링크의 자료와 도구·라이브러리는 각 원출처의 조건을 따른다.

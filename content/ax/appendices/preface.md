# 독서·실습 안내

《AX 완전 정복》은 AI 전환을 업무의 문제, 자료, 시스템과 조직 운영을 함께 바꾸는 과정으로 다룬다. 리더·기획자·업무 담당자·개발자가 같은 과제를 서로 다른 관점에서 검토할 수 있도록 7부·30장과 실습 양식을 구성했다.

## 읽는 경로

- 처음 계획하는 팀: 1~9장으로 문제·준비도·범위·비용을 정하고 29~30장으로 실행계획을 만든다.
- 업무 담당자·검토자: 10~14장, 20장, 25~27장에서 흐름·근거·인계·교육·측정을 연결한다.
- 개발·운영자: 15~24장에서 데이터·권한·RAG·도구·평가·복귀를 설계한다.
- 리더·업무 소유자: 5~9장, 23~28장, 30장에서 투자·책임·변화·확대 조건을 검토한다.

특정 경로로 시작해도 자료 권한과 위험 검토, 책임과 대체 흐름을 생략하지 않는다. 설계는 역할별로 분리되지만 실제 업무에서는 연결되어야 한다.

## 실습 방식

각 장의 실습으로 [13종 워크시트](workbook.md)를 채운다. [솔빛서비스 실습 자료](../examples/README.md)는 모두 가상이다. Python 계산기와 구조 테스트는 API 키 없이 로컬 실행할 수 있다. 별도의 AI 모델을 사용하려면 처리 조건과 비용·자료 사용 권한을 확인한다.

솔빛서비스의 수치와 정책은 실제 회사 사례, 벤치마크나 성능 실적이 아니다. 예제의 평가 기대 행동은 저자 제안이며 조직의 정책을 검토하는 출발점이다. 작은 테스트를 통과했다고 실제 업무의 안전과 적법성이 보장되지 않는다.

## 작성과 검증

이 원고는 사용자가 승인한 목차를 바탕으로 이 대화에서 Codex가 작성했다. book-generator는 외부 원고 패키징 기능으로 목차·메타데이터·ZIP을 정리했다. 생성기의 별도 OpenAI·Claude·Gemini API 호출은 없었다. 작성에 사용된 Codex의 정확한 모델 식별자는 확인되지 않아 메타데이터에 `null`로 기록한다.

내용은 AI 작성 초안이다. 출처, 법령 확인 범위와 실제 실행한 검사는 [검증 기록](verification.md)에 구분해 남긴다. 전체 사람 검수와 실제 기업 적용·모델 성능 평가를 완료한 책으로 표시하지 않는다. 기준일은 2026년 10월 13일이며, 달라질 수 있는 법령·가격·제품 조건은 실제 사용 시 다시 확인한다.

## 기여하는 방법

원고의 오류나 더 좋은 예제가 있으면 문제 위치, 근거, 확인 날짜와 제안 변경을 함께 남긴다. 실습 실행을 검증했다면 환경과 명령, 결과와 미확인 범위를 기록한다. 개인정보·비밀·외부 자료의 무단 복제는 기여 파일에 포함하지 않는다.

이 책의 원고와 저자 작성 양식·가상 예제는 books 저장소의 CC0 배포 정책을 따른다. 연결된 외부 자료와 법령 사이트, 도구·라이브러리의 이용 조건은 각 원출처를 확인한다.

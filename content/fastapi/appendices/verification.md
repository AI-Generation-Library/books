이 책은 2026년 10월 10일 기준의 로컬 작성·검증 원고다. 코드 문법 검사, 최소 실행 검사, 실제 외부 시스템 검증을 구분한다. 본문에 나온 모든 운영 구성을 배포해 검증했다는 뜻은 아니다.

검증에 사용한 라이브러리 설치 결과는 [requirements.verified.txt](requirements.verified.txt)에 기록했다. 이 파일은 로컬 검증 환경의 스냅샷이다. 모든 장의 운영 확장에 필요한 도구와 패키지를 전부 포함하는 파일이 아니며, 다른 OS의 동일 동작을 자동으로 보장하지 않는다. PostgreSQL·Redis·Celery·LangGraph·k6 등 각 실습의 추가 구성은 해당 장에서 별도로 확인한다.

책의 기본 설치 범위는 학습용 API 기준이고 위 표는 실제 검사한 조합이다. 새 환경에서 다른 버전이 선택되면 테스트를 먼저 실행하고 결과를 기록한다. 검증 환경의 TestClient에서 HTTPX 사용에 관한 deprecation 경고를 관찰했으며, 해당 경고가 있는 상태에서 로컬 검증은 통과했다. 의존성을 업데이트할 때 공식 테스트 클라이언트 문서와 마이그레이션 안내를 확인한다.

문법 검사를 통과한 **개념 예제**에는 설치 환경이나 생략한 도메인 객체를 전제로 하는 코드가 있을 수 있다. AST 통과는 import 성공, 외부 서비스 연결, 운영 안정성의 보장이 아니다. 실행 예제와 개념 예제는 각 본문에서 구분한다.

## 측정 결과의 해석

1~8장 로컬 검사에서는 비동기 sleep과 블로킹 sleep을 각각 8개 동시 ASGI 요청으로 호출해 기다림이 겹치는 방향과 직렬화되는 방향을 확인했다. 실제 네트워크·DB·LLM이 없는 모의 대기이며 서비스 처리량 벤치마크가 아니다. 본문에 나온 RPS, SSE 연결 수, 비용·메모리 계산은 가정이라고 표시한 교육용 설계 문제다.

HTTPX ASGITransport와 TestClient는 애플리케이션 실행을 검증한다. 네트워크 파서, OS 소켓 한도, TLS, 프록시 버퍼링, 실제 브라우저 재연결은 별도 환경 검증이 필요하다. 같은 컴퓨터의 타이밍 결과를 다른 서버의 목표 성능으로 사용하지 않는다.

## 외부 환경에서 실행하지 않은 내용

실제 PostgreSQL 연결과 락·격리·풀 포화, Redis 캐시·Lua 요청 제한, Celery 브로커·worker, pgvector 인덱스, 외부 LLM·GPU 추론, LangGraph 영속 checkpoint 연동은 로컬 통합판 검증에 포함하지 않았다. Docker 이미지 빌드·Compose 서비스 기동·Nginx/TLS 배포·무중단 전환·k6 부하·외부 Prometheus/Grafana/OTel/Sentry 연동도 실제 실행 결과로 주장하지 않는다.

해당 장은 필요한 설계 원리, 구성 예제, 실행 절차, 결과 판단 기준을 제공한다. 자신의 실습 환경에서 실행할 때는 먼저 작은 데이터로 연결을 확인하고, 정상·실패·취소·재시작을 검증한 뒤 부하를 늘린다.

## 통합판 재현

외부 모델 호출 없이 실행하는 [29장 프로젝트](../29-capstone/project/README.md)는 별도의 requirements와 테스트를 제공한다. 그 README가 있는 디렉터리에서 가상환경을 만들고 의존성을 설치한 뒤 `python -m pytest -q`를 실행한다. 서버를 시작하려면 같은 README의 비밀 키 생성과 Uvicorn 실행 명령을 따른다.

이 프로젝트의 답변은 단어 기반 검색과 문서 발췌다. 문자 수 기반 mock_units는 실제 모델 토큰·통화 비용이 아니다. 단일 프로세스용 시작 복구 규칙을 다중 워커에 그대로 적용하면 안 된다. 실제 운영 확장은 29장 본문과 프로젝트 README에 분리해 적었다.

# 36장. 멀티모달 RAG

## 학습 목표

- 텍스트만으로 잃는 표·그림·레이아웃을 구분한다.
- 시각 검색과 생성의 근거 위치·비용을 평가한다.

## 페이지에는 텍스트 밖의 정보가 있다

흐름도·차트·도면·복잡한 표는 단순 추출 텍스트로 관계를 잃을 수 있다. OCR이 글자를 읽어도 화살표·색·행열 대응·범례를 보존하지 못할 수 있다. 이런 자료에서는 페이지 이미지나 영역을 검색하고 시각 근거를 생성 모델에 제공하는 접근을 검토한다.

문서 이미지 검색·이미지 캡션 검색·OCR 텍스트 검색은 서로 다른 파이프라인이다. 캡션을 만들어 검색하면 추론 과정의 오류가 들어갈 수 있고, 원본 이미지를 직접 인코딩하면 모델·저장·전송 비용이 달라진다. 무엇을 실제 구현했는지 명시한다.

## 표현과 검색

텍스트·이미지를 같은 공간으로 인코딩하는 모델도 있고 페이지의 여러 패치 표현을 사용하는 접근도 있다. 모델이 지원하는 입력 종류·해상도·길이·언어를 확인한다. ColPali는 문서 시각 표현과 late interaction을 활용하는 연구 사례다. 모든 멀티모달 검색을 같은 방식으로 묶지 않는다.

질문이 문장 내용을 묻는지 표의 특정 셀과 단위를 묻는지에 따라 필요한 근거가 다르다. 잘못된 페이지를 높은 유사도로 찾거나 올바른 페이지의 다른 셀을 읽는 실패를 구분한다.

## 인용 위치

문서 ID·버전·페이지·영역 좌표·추출 변환을 보존한다. 이미지가 크기 변경·회전·크롭되면 원본 좌표로 돌아갈 수 있어야 한다. 표 수치의 행·열 제목과 단위를 함께 보여 줘야 사용자가 검증할 수 있다.

시각 모델이 읽은 값을 구조화 JSON으로 반환해도 내용이 맞다는 보장은 아니다. 셀 값·단위·부정·차트 축 해석을 평가한다. 생성한 설명은 원본 그림 자체와 다른 파생 자료다.

## 권한·용량·평가

페이지 이미지에 본문 텍스트보다 많은 개인정보와 주변 정보가 포함될 수 있다. 검색·크롭·외부 모델 전송에서 권한과 최소화를 유지한다. 이미지 토큰·해상도·페이지 수·다운로드·저장 비용을 기록한다.

OCR-only·캡션·시각 검색을 같은 자료에서 비교하고 페이지 검색·영역 검색·최종 수치 답변을 별도 평가한다. 이번 종합 프로젝트는 텍스트 검색과 PDF 텍스트 추출을 실행했으며 멀티모달 embedding·OCR·시각 생성 모델 추론은 미검증이다.

## 실습과 평가

한 장짜리 가상 표를 텍스트로 변환했을 때 사라지는 행·열·단위를 기록한다. PDF 파서의 needs_ocr 표시는 OCR 실행 결과가 아니라 텍스트 레이어 부재 신호임을 확인한다.

멀티모달 확장을 구현할 때는 원본 페이지와 영역 인용, 잘못된 셀을 읽는 negative 질문을 평가셋에 추가한다.

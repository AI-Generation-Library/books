# 읽는 방법과 실습 기준

## 전체 흐름

1부에서 최소 RAG와 기준선을, 2부에서 문서 처리, 3~4부에서 검색과 개선, 5부에서 생성과 근거, 6부에서 평가, 7부에서 운영을 배운다. 8부는 적용 조건을 포함한 고급 설계이며 9부에서 검증 가능한 서비스를 통합한다.

명령은 별도 표시가 없으면 examples 디렉터리에서 실행한다. 본문의 짧은 코드·SQL은 개념 조각일 수 있다. 실행 명령과 제공 파일을 기준으로 재현하고 문법 검사와 실제 실행을 구분한다.

## 두 벡터·두 생성 모드

CharacterEmbedder는 문자 2-gram 해시 벡터로 학습된 의미 모델이 아니다. ExtractiveGenerator는 원문 발췌이며 LLM 생성이 아니다. 작은 환경에서 수학·수명·권한·인용을 검증하기 위한 기본값이다.

선택형 FastEmbedder는 다국어 ONNX 모델, FastCrossEncoder는 다국어 리랭커, OllamaGenerator는 로컬 생성 모델을 호출한다. 실제 실행한 모델·digest·출력과 질문 수는 검증 기록에 있다. 외부 유료 API 키를 요구하지 않지만 모델 다운로드와 로컬 자원은 필요하다.

## 환경과 버전

Windows / Python 3.12.12에서 확인했다. 직접 의존성과 전이 의존성 snapshot을 예제에 제공한다. 다른 OS·Python 버전·모델이 같은 결과를 낸다고 보장하지 않는다. Windows 출력 인코딩은 필요하면 python -X utf8로 맞춘다.

기본 청킹·컨텍스트 예산은 문자 수다. 실제 모델의 토큰 윈도와 같은 단위로 부르지 않는다. 인용 start/end는 정규화 본문 기준이며 원본 PDF 화면 좌표가 아니다.

## 평가의 해석

가상 문서 7개와 질문 8개는 교육용 fixture다. test split이라고 이름 붙였어도 독립 산업 벤치마크가 아니다. qrels는 문서 단위이고, 검색 지표 평균은 answerable 사례를 대상으로 한다. 거절 성능과 의미적 답변 정확성은 다른 평가다.

출처 ID와 quote가 맞아도 주장은 틀릴 수 있다. 예제의 한계를 테스트로 명시했다. 전체 사람 검수와 광범위한 실제 사용자 품질·보안·운영 검증은 별도로 필요하다.

# 26장. 답변과 인용 품질 평가

## 학습 목표

- 정확성·충실성·완전성·관련성을 따로 평가한다.
- 부분적으로 맞는 긴 답변을 사실 단위로 검토한다.

## 하나의 정답 점수로 부족한 이유

답변이 원문에 충실해도 원문이 오래되었거나 틀릴 수 있다. 실제 정답이 맞아도 검색 근거에는 없는 지식을 모델이 기억해서 말했을 수 있다. 질문과 관련된 답이라도 필요한 예외를 빠뜨릴 수 있다. 서로 다른 품질 축을 분리해야 개선할 단계를 알 수 있다.

| 축 | 확인할 질문 |
| --- | --- |
| 정확성 | 기대한 사실·수치·조건이 맞는가 |
| 근거 충실성 | 답변 주장이 제공한 근거에 지지되는가 |
| 완전성 | 질문에 필요한 주요 사실을 빠뜨리지 않았는가 |
| 관련성 | 질문과 무관한 내용을 늘어놓지 않는가 |
| 인용 품질 | 출처가 정확하고 필요한 주장에 충분히 붙었는가 |

## 원자적 사실로 나누기

휴가가 15일이고 신청은 3일 전이라는 문장은 두 개의 사실을 포함한다. 하나만 맞으면 전체를 무조건 정답으로 표시하는 대신 사실별 지지·누락·모순을 기록한다. 수치의 단위와 적용 대상까지 평가 항목에 포함한다.

정답 표현이 여러 가지일 수 있으므로 문자열 완전 일치만으로 자연어 답변을 평가하면 틀리지 않은 답을 거부할 수 있다. 반대로 답변에 15라는 숫자가 있다는 검사만으로 사실 전체가 맞다고 증명할 수도 없다. 단순 검사는 smoke 범위를 명확히 한다.

## 인용 검사의 계층

출처 멤버십·quote 문자열·의미적 지지를 구분한다. 예제의 자동 인용 검사는 처음 두 가지뿐이다. 테스트에는 틀린 주장과 실제 부분 문자열을 함께 넣어 통과하는 경우를 명시했다. 자동 검사가 한계를 드러내는 자료가 될 수 있다.

의미적 평가를 추가하려면 사람이 정의한 기준표와 평가 모델의 결과를 비교한다. 부정·예외·표·한국어 수치 문장에서 일관되게 판정하는지 확인한다. 근거 밖 세계 지식을 사용해 판정할지 원문만으로 판정할지도 명시한다.

## 거절 품질

답할 수 없는 질문을 거절하는 능력과 답할 수 있는 질문을 과도하게 거절하지 않는 능력을 함께 본다. 모든 질문을 거절하면 허위 답변이 적어도 서비스는 쓸모없을 수 있다. 유형별 confusion matrix와 비용을 검토한다.

실제 LLM smoke는 한국어 가상 질문 1건에서 15일과 올바른 인용을 반환했다. 이는 생성 연결과 해당 결과의 관측이다. 여러 유형의 정확성·충실성·보안 평가를 완료한 수치로 사용하지 않는다. 실제 출력·모델 digest·조건을 부록에 남긴다.

## 실습과 평가

llm-results.json의 answer·quote·document_id·version을 원문과 비교한다. 자동 smoke가 확인한 조건과 사람이 추가로 평가해야 할 사실 항목을 나눈다.

정답·부분 정답·모순·과도한 거절 예시를 작은 평가표로 만들고 같은 기준으로 여러 사람이 판정할 수 있는지 검토한다. 이번 집필의 전체 사람 검수는 미수행이다.

# 핵심 용어

| 용어 | 의미 |
| --- | --- |
| RAG | 질문별 외부 근거를 검색해 생성 모델 입력에 연결하는 구조. |
| 색인 | 질의를 위해 문서·표현·메타데이터를 준비하는 과정과 자료 구조. |
| 청크 | 검색·입력 예산을 위해 나눈 문서의 구간. |
| 오버랩 | 이웃 청크가 공유하는 원문 구간. 중복과 저장 비용도 늘 수 있다. |
| 정규화 | 문자·공백 등을 정한 규칙으로 변환하는 과정. 원문 보존과 구분한다. |
| 임베딩 | 입력을 벡터로 표현한 값. 모든 벡터가 학습된 의미 표현인 것은 아니다. |
| bi-encoder | 질문과 문서를 따로 인코딩해 비교하는 모델 구조. |
| cross-encoder | 질문과 후보를 함께 입력해 관계를 점수화하는 구조. |
| 코사인 유사도 | 벡터 방향의 유사성. 정답 확률이 아니다. |
| 벡터 차원 | 벡터 좌표 수. 같은 차원이어도 다른 모델 공간은 섞을 수 없다. |
| BM25 | 단어 희소성·빈도·길이 보정을 이용한 검색 점수 계열. |
| 역색인 | 단어에서 해당 문서·빈도 등으로 연결하는 검색 자료 구조. |
| ANN | 모든 벡터를 정확 순회하는 대신 근사적으로 이웃을 찾는 방식. |
| HNSW | 계층적 근접 그래프로 벡터 이웃을 탐색하는 ANN 방법. |
| IVF | 벡터를 여러 목록으로 나눠 일부를 검색하는 인덱스 계열. |
| 하이브리드 검색 | 키워드·벡터 등 여러 검색 결과를 결합하는 방식. |
| RRF | 각 검색의 순위를 역수 기반으로 합치는 방식. 완화 상수와 반환 개수는 다르다. |
| 리랭킹 | 이미 찾은 후보를 더 정밀한 모델 등으로 다시 정렬하는 과정. |
| MMR | 질문 관련성과 선택한 근거와의 중복을 함께 고려하는 선택 방법. |
| HyDE | 가상 답변 문서를 생성해 검색 표현으로 쓰는 접근. 가상 문서는 사실 근거가 아니다. |
| Parent-child | 작은 자식으로 찾고 큰 부모 문맥을 제공하는 검색 구조. |
| Multi-hop | 여러 검색·근거 연결이 필요한 질의 처리. |
| 컨텍스트 | 모델 입력에 제공한 지시·질문·근거 등 현재 문맥. |
| 토큰 | 모델 토크나이저의 입력/출력 단위. 문자·바이트와 다르다. |
| groundedness | 답변이 제공한 근거에 지지되는 정도. 현실 사실 정확성과 구분한다. |
| 충실성 | 주장을 근거 밖으로 확장하거나 모순하지 않는 성질. |
| 인용 정확성 | 붙인 출처·구간이 해당 주장을 실제 지지하는지의 성질. |
| 인용 완전성 | 근거가 필요한 주요 주장에 충분한 인용이 붙었는지의 성질. |
| answerability | 현재 허용 근거로 질문에 답할 수 있는지의 판단. |
| abstention | 근거 부족 등 이유로 답을 단정하지 않고 거절하는 행동. |
| qrels | 질문별 관련 항목과 등급을 기록한 정답 라벨. |
| Precision@k | 상위 k개 중 관련 항목 비율. 분모 정책을 명시한다. |
| Recall@k | 전체 관련 항목 중 상위 k에서 찾은 비율. |
| MRR | 첫 관련 항목의 순위 역수를 질문별 평균한 지표. |
| nDCG | 순위·관련성 등급을 반영한 누적 이득을 이상 순위와 비교한 지표. |
| hard negative | 비슷하지만 실제 정답 근거가 아닌 학습·평가 후보. |
| ablation | 구성 요소를 빼거나 바꿔 기여를 분리하는 실험. |
| 데이터 누출 | 평가 정보를 학습·선택에 사용해 결과를 과대평가하는 문제. |
| LLM-as-judge | 모델을 평가 보조자로 사용하는 방식. 편향과 오류를 검증해야 한다. |
| tenant | 조직 등 데이터를 격리하는 서비스 경계. |
| ACL | 사용자·역할에 대한 접근 허용 정책. |
| 프롬프트 주입 | 문서·입력의 지시로 모델의 의도한 행동을 바꾸려는 공격. |
| snapshot | 특정 시점·revision의 데이터 상태. |
| 모델 signature | 모델·파일·전처리 등 인코딩 계약을 식별하는 값. |
| Agentic RAG | 모델이 제한된 도구로 검색 시점·방식을 동적으로 선택하는 구조. |
| GraphRAG | 그래프와 파생 요약 등을 검색·답변에 활용하는 접근. 특정 구현과 일반 개념을 구분한다. |
| 멀티모달 RAG | 텍스트·이미지·표 등 여러 표현의 근거를 검색·생성에 활용하는 구조. |
| late interaction | 질문·문서의 여러 토큰 표현을 후단에서 결합해 비교하는 접근. |
| 증류 | 교사 모델의 정보를 학생 모델 학습에 사용하는 과정. |
| 색인 지연 | 원본 변경이 검색 가능한 상태로 반영되기까지의 시간. |

# 학습 경로

| 목표 | 권장 순서 | 확인할 결과 |
| --- | --- | --- |
| 첫 RAG | 1~9 → 10~14 → 20~22 | 기본 검색과 발췌·실제 생성의 차이를 설명한다. |
| 검색 개선 | 4 복습 → 10~19 → 24~28 | 같은 평가셋에서 단일 변수를 비교한다. |
| 신뢰 가능한 답변 | 20~28 → 31 | 근거 존재·의미적 지지·거절·권한을 구분한다. |
| 서비스 운영 | 29~33 → 38~40 | 수정·삭제·권한·모델/인덱스 변경을 검증한다. |
| 고급 설계 | 기준선과 평가 확보 → 34~37 | 추가 복잡성의 이득·실패·비용을 설명한다. |

각 단계에서 정상 질문 하나와 실패 질문 하나를 재현한다. 프레임워크를 먼저 보고 싶다면 examples/README의 기본 index를 만든 뒤 demos.frameworks를 실행하고 원래 검색·권한 코드를 거슬러 읽는다.

평가 기준을 만들기 전에 복잡한 기법부터 쌓지 않는다. 실제 모델 연결이 어려우면 기본 모드로 제어 흐름을 검증하고 모델 실행은 별도 기록한다.

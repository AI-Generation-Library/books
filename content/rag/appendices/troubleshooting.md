# 실패 진단

| 증상 | 먼저 확인할 것 |
| --- | --- |
| 원문이 검색되지 않음 | 수집·파싱·활성 문서·권한·tokenization·후보 수 |
| 원문 있는데 빈 추출 | PDF 스캔·암호화·읽기 순서·파서 실패 |
| 숫자/예외가 빠짐 | 청크 경계·모델 입력 절단·표 단위 |
| embedding mismatch | DB·모델·캐시·파일 hash·전처리 계약 |
| dimension mismatch | 다른 모델 벡터 혼합·잘못된 어댑터 |
| 권한 밖 자료 노출 | tenant/ACL 적용 시점·리랭커/캐시/로그 |
| 점수 높지만 오답 | 주제 유사성과 근거 충분성·생성 오류 분리 |
| invalid_citation | JSON 타입·ID·원문 quote·출력 잘림 |
| model_abstained | 근거 충분성·프롬프트·모델의 거절 |
| context_changed | 생성 중 개정·삭제·권한 변경 |
| 502 | 로컬 모델 준비·API 호환·기한·연결 상태 |
| 모델 다운로드 실패 | 네트워크·캐시 경로·디스크·공개 모델 접근 |
| 테스트 정지 | 실행 환경의 스레드/파일/네트워크 제한과 열린 자원 |
| 한국어 출력 깨짐 | UTF-8 파일과 콘솔 인코딩을 구분, python -X utf8 |

원문→파싱→청크→권한 후보→검색 순위→컨텍스트→생성→인용 순서로 원인을 좁힌다. 실패 명령·OS·패키지·모델 signature·문서 revision을 기록하되 토큰과 실제 비밀 문서는 공유하지 않는다.

문법·단위 테스트·실제 모델·광범위한 품질·공개 배포는 다른 검증이다. 스크립트가 존재한다는 사실을 실행 성공으로 적지 않는다.

# 실습 데이터 사전

모든 CSV는 이 책의 `create_data.py`로 생성한 가상 데이터다. 실제 고객·기업·개인정보가 없고 공식 시험 자료도 아니다. 난수 seed는 20261013이다. 분류·회귀 각 600행이며 관측 간 독립을 가정한다.

## customers.csv

| 열 | 의미·단위 | 역할·품질 |
| --- | --- | --- |
| customer_id | 가상 고객 식별자 | 고유, 모델 입력 제외 |
| tenure_months | 이용 기간, 개월 | 숫자 특성 |
| monthly_fee | 요금, 가상 금액 단위 | 결측·음수·극단값 연습 |
| support_calls | 지원 문의 수 | 숫자 특성 |
| last_usage | 이전 이용 지수, 0~100 | 범위 위반 연습 |
| contract_type | monthly / yearly | 결측 포함 범주 |
| region | east / west / south | 범주 |
| churn | 0 유지, 1 이탈 | 이진 타깃 |

요금은 0 이상, 이용 지수는 0~100이라는 고정 정의를 둔다. 음수는 결측으로 바꾸는 기본 예제를 사용한다. 10000 요금은 통계적으로 드물지만 정의만으로 오류라고 판정하지 않는다. 타깃은 인위적인 확률식과 난수로 생성했으므로 결과를 실제 이탈 원인·성능으로 일반화하지 않는다.

## service_usage.csv

| 열 | 의미·단위 | 역할 |
| --- | --- | --- |
| record_id | 가상 관측 식별자 | 고유, 모델 입력 제외 |
| active_users | 활동 사용자 수 | 숫자 |
| active_days | 활동 일수 | 숫자 |
| storage_gb | 저장량, GB | 결측 포함 숫자 |
| plan | basic / pro | 범주 |
| region | east / west / south | 범주 |
| usage_hours | 서비스 이용 시간 | 연속 타깃 |

이 자료는 월별 시계열이 아니다. 실제 반복 고객·장비·기간 자료라면 그 단위에 맞는 분할이 필요하다. 타깃 생성식과 잡음은 학습용이며 실제 서비스 예측 관계를 주장하지 않는다.

## regions.csv

지역별 zone 설명을 가진 3행 사전이다. `region`은 고유 키이며 고객 표와 many-to-one 결합을 연습한다. zone의 순서에 사업적 의미는 없다.

CSV를 임의 수정하면 문제의 예상 구조·결측 수와 실행 결과가 바뀐다. 변경했다면 데이터 버전과 문제의 기대 조건도 함께 기록한다.

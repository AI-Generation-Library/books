# 09장. 상관관계와 타깃 분석하기

타깃은 모델이 예측할 값이다. 어떤 열을 예측하는지와 예측 시점에 입력으로 사용할 정보를 먼저 정한다. 상관계수가 큰 열을 자동으로 좋은 특성으로 선택하면 타깃 자체나 이후에 알 수 있는 정보를 포함할 수 있다.

## 1. 타깃 분포와 기준

이진 분류에서는 두 클래스의 개수·비율을 본다. 한 클래스가 대부분이라면 무조건 그 클래스만 예측해도 정확도가 높아질 수 있다. 회귀에서는 타깃 단위와 분포, 음수·결측·극단값을 확인한다. 평가 지표도 타깃과 문제 목적에 맞춘다.

```python
import pandas as pd
from lab import split_task

X_train, X_val, X_test, y_train, y_val, y_test = split_task()
train = X_train.copy()
train["churn"] = y_train
numeric = train.select_dtypes(include="number")
correlations = numeric.corr()["churn"].drop("churn").sort_values()
counts = y_train.value_counts().sort_index()
rates = y_train.value_counts(normalize=True).sort_index()
assert len(X_train) == len(y_train) == 360
assert abs(rates.sum()-1) < 1e-10
print(counts, rates, correlations)
```

## 2. 상관계수의 의미와 한계

피어슨 상관계수는 두 숫자의 선형 관계를 요약한다. 0에 가깝다고 모든 관계가 없는 것은 아니고, 높다고 한 변수가 다른 변수를 원인으로 바꾸는 것도 아니다. 이상치와 집단 구성의 영향을 받을 수 있다.

상관표의 대각선은 자기 자신과의 관계다. 타깃을 제거하지 않으면 타깃과 타깃의 상관 1을 최고의 특성으로 잘못 선택할 수 있다. 범주에 임의 숫자를 붙여 피어슨 상관을 계산하면 숫자의 순서가 근거 없는 의미를 만들 수 있다.

## 3. 예측 시점의 정보

고객 이탈을 예측하면서 실제 해지 사유나 해지 이후의 처리 정보를 입력에 넣으면 예측 시점에 사용할 수 없는 정보가 들어간다. 식별자도 단순 숫자 특성으로 처리하지 않는다. 자료 사전에서 사용 가능한 입력을 명시적으로 고른다.

통계적으로 관계가 강한 열과 업무적으로 사용 가능한 열은 다르다. 이 책의 기본 모델은 미리 정한 특성 목록만 사용하며 타깃과 ID를 제외한다. 실제 데이터에서는 수집 시점과 그룹·기간을 더 확인해야 한다.

## 4. 탐색과 평가를 분리하기

탐색은 가설을 찾는 과정이다. 그 가설을 검증하는 자료까지 보고 설정을 맞추면 독립 평가가 약해진다. 자료 품질의 고정 규칙과 데이터에서 학습하는 통계·변환을 구분한다. 분할·전처리·평가의 정확한 순서는 다음 부에서 다룬다.

## 연습과 해설

1. 상관이 낮은 변수는 항상 삭제해야 하는가? **해설:** 비선형 관계와 다른 변수와의 조합이 있을 수 있다. 사용 가능성과 검증 결과를 함께 본다.

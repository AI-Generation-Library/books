# 03장. 실습에 필요한 Python과 NumPy

데이터 분석 코드에서 가장 자주 확인할 것은 값의 종류와 형태다. 숫자처럼 보이는 문자열은 계산할 수 없거나 문자열 결합으로 처리될 수 있다. 하나의 열을 꺼내면 1차원인지 2차원인지에 따라 모델이 받는 입력이 달라진다.

## 1. 자료형과 순서

리스트는 순서가 있는 값 묶음이고 딕셔너리는 이름과 값을 연결한다. 인덱스는 0부터 시작하며 슬라이스의 끝은 포함하지 않는다. `values[1:3]`은 두 번째·세 번째 원소다. 필터 조건과 비교 연산이 만드는 불리언 값도 중요하다.

함수는 반복 작업을 묶고 입력·출력을 명확히 한다. 반환값이 없으면 `None`이므로 결과를 변수에 저장해도 원하는 자료를 받지 못할 수 있다. 변수명을 같은 의미로 유지하고, 데이터 전체와 입력 `X`, 타깃 `y`를 구분한다.

## 2. NumPy 배열의 형태

표 형태의 모델 입력은 보통 `(샘플 수, 특성 수)`다. 타깃은 모델과 손실에 따라 `(샘플 수,)` 또는 `(샘플 수, 출력 수)`가 된다. `shape`를 확인하면 많은 오류를 빨리 찾을 수 있다.

```python
import numpy as np

fees = np.array([20.0, 30.0, 40.0])
X = fees.reshape(-1, 1)
y = np.array([0, 1, 0])
assert X.shape == (3, 1)
assert y.shape == (3,)
mask = fees >= 30
assert fees[mask].tolist() == [30.0, 40.0]
assert np.isclose(fees.mean(), 30.0)
print(X.shape, y.shape, fees[mask])
```

`-1`은 전체 원소 수에 맞춰 해당 차원을 계산하라는 뜻이다. 배열의 형태를 바꾸어도 샘플 순서가 올바른지 확인해야 한다. `reshape`로 오류를 없앴다는 사실만으로 올바른 데이터가 된 것은 아니다.

## 3. 축과 계산

2차원 배열에서 `axis=0`은 행 방향을 줄여 각 열을 요약하고 `axis=1`은 열 방향을 줄여 각 행을 요약한다. 평균의 단위를 생각하면 축을 선택하기 쉽다. 고객별 평균을 구하려는지 변수별 평균을 구하려는지 먼저 말로 설명한다.

배열끼리 연산할 때 형태에 따라 방송 연산이 일어난다. `(n,)`과 `(n,1)`을 빼면 의도와 달리 `(n,n)`이 될 수 있다. 회귀 평가에서 실제값·예측값을 모두 1차원으로 맞추고 길이를 확인한다.

## 4. 결측과 비교

부동소수점 결측을 나타내는 `np.nan`은 일반 값처럼 같다고 비교하지 않는다. NumPy에서는 `np.isnan`, pandas에서는 `isna`를 사용한다. 문자와 결측이 섞인 배열은 숫자 연산 전에 자료형을 확인한다.

실수 계산은 근사 표현을 사용하므로 완전히 같은지 비교하는 대신 필요할 때 `np.isclose`를 쓴다. 반면 클래스 라벨과 행 수처럼 정확한 값에는 정확한 비교가 맞다. 모든 오류를 반올림으로 숨기지 않는다.

## 5. 오류를 입력에서 읽기

`TypeError`는 연산과 자료형이 맞는지, `IndexError`는 인덱스 범위가 맞는지, `ValueError`는 형태·값 조건이 맞는지 먼저 본다. 오류 메시지 전체와 실패 줄을 읽고 관련 변수의 `type`, `shape`, 일부 값을 출력한다.

뒤의 예제는 표 데이터에 집중한다. 이미지·자연어 모델을 만들기 위해 배열을 더 복잡하게 바꾸는 내용은 이 책의 기본 학습 경로에 포함하지 않는다.

## 연습과 해설

1. 한 특성에 샘플 네 개가 있다면 입력 형태는? **해설:** `(4,1)`이다. `(1,4)`는 샘플 하나에 특성 네 개라는 다른 의미다.
2. 예측과 실제값의 길이는 같지만 차원이 다르다. 무엇을 확인해야 하는가? **해설:** 둘의 `shape`와 차이를 계산한 결과의 형태를 확인한다.

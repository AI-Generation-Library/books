# 30장. 자체 제작 실전 모의고사 2회

이 장의 모의고사는 책을 위해 새로 만든 학습 문제다. 공식 기출·공개 샘플의 복제나 실제 문항 예측이 아니다. 각각 14문항·90분 연습으로 전체 분석 과정을 확인한다. 자체 채점 기준은 실제 시험의 채점 로직과 다르다.

## 1. 구성과 시작 방법

| 회차 | 자료·타깃 | 주요 연습 |
| --- | --- | --- |
| 1회 | 고객 600행, churn | 분석·품질·전처리·분류·확률·평가 |
| 2회 | 서비스 600행, usage_hours | 집계·전처리·회귀·딥러닝·오차·그림 |

[1회 문제](../examples/mock-01-questions.md)와 [2회 문제](../examples/mock-02-questions.md)를 먼저 읽는다. 각 문제의 지정 변수·조건·설정을 체크한다. `examples` 폴더에서 학습용 답안 노트북을 열고 해설을 보지 않은 상태로 풀이한다.

처음에는 시간 제한 없이 원리를 확인해도 된다. 이후 90분을 두고 실행·오류 수정·검토까지 연습한다. 타이머가 끝나면 추가 수정 전의 상태와 미완료를 기록한다. 나중에 고친 답을 최초 완료 결과로 바꾸지 않는다.

## 2. 학습용 배점

두 회차는 분석 5문항 각 6점, 전처리 5문항 각 6점, 모델·평가 4문항 각 10점의 자가평가 예시로 구성했다. 합계는 100점이다. 이 배점과 요구조건별 부분 점수는 저자 작성이며 공식 시험의 문항 배점·자동 채점 규칙을 복제한 것이 아니다.

자동 검사로 형태·참조·산출물과 일부 값·모델 설정을 확인할 수 있다. 그래프의 적절성, 조건 준수와 설명은 직접 대조한다. 코드가 실행되었다는 사실만으로 모든 문항을 정답 처리하지 않는다. 특정 수치의 모델 성능을 합격 기준으로 요구하지 않는다.

## 3. 풀이와 해설 사용

풀이 후 [1회 해설](../examples/mock-01-solutions.md)·[2회 해설](../examples/mock-02-solutions.md)과 비교한다. 정답 코드가 같아야 하는 것은 아니지만 지정 조건과 산출물은 맞아야 한다. 완성된 해설 노트북은 같은 데이터에서 실행해 확인할 수 있다.

오답을 입력·탐색·전처리·모델·평가·저장으로 나눈다. 인코딩 열 불일치, 타깃 포함, 테스트 fit, 출력·손실 불일치, ID 순서 오류는 원인을 설명한 뒤 새 작은 사례로 다시 확인한다. 같은 데이터의 답을 외우는 것으로 복습을 끝내지 않는다.

## 4. 결과 기록

소요 시간과 문항별 완료·실행 오류·조건 누락을 남긴다. 두 번째 회차는 문제와 타깃이 다르므로 점수 차이를 그대로 능력 증가로 해석하지 않는다. 자체 점수는 약점을 찾기 위한 기록이며 실제 합격 확률이 아니다.

[학습 계획](../appendices/study-plan.md)의 남은 수행을 다시 확인한다. 공식 안내·샘플·사전 환경점검을 제공 조건에 맞춰 직접 확인하고 시험 회차의 규정을 따른다. 이 책의 자료와 노트북이 시험 중 허용된다고 가정하지 않는다.

## 5. 학습을 마친 뒤

새 파일과 조건에서도 데이터를 읽고 구조·품질을 설명하며, 타깃과 입력을 분리하고, 훈련에서 전처리를 학습해 다른 집합에 적용할 수 있는지 확인한다. 분류·회귀의 지표와 신경망 손실·출력 조합을 설명하고 처음부터 실행할 수 있어야 한다.

시험 준비 과정에서 익힌 흐름은 작은 정형 데이터 분석의 기본이 된다. 실제 업무에서는 개인정보·자료 권리·예측 시점·그룹과 기간, 운영 책임을 더 확인해야 한다. 자격시험 실습과 실제 업무 운영의 범위는 다르다.

## 확인 질문과 해설

1. 해설을 복사해 실행한 결과를 독립 풀이 점수로 기록해도 되는가? **해설:** 독립 풀이와 해설 확인을 구분한다.
2. 모든 자동 검사를 통과하면 실제 합격을 보장하는가? **해설:** 자체 문제의 검사 범위일 뿐이며 실제 출제·채점과 조건은 별개다.

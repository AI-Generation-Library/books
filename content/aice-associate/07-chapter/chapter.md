# 07장. 데이터 구성과 품질 점검하기

좋은 탐색은 모델에 넣을 자료가 무엇인지 이해하게 한다. 모든 열의 평균을 출력하는 것으로 끝내지 말고 각 열의 의미, 단위, 결측과 허용 범위, 타깃 분포와 중복을 확인한다. 이후 어떤 전처리가 필요한지 연결해야 한다.

## 1. 형태·자료형·통계

`shape`, `columns`, `dtypes`, `info`로 구조를 확인한다. `describe`는 숫자 열의 분포를 빠르게 볼 수 있지만 ID처럼 숫자로 저장된 범주나 식별자를 평균 내는 것은 의미가 다르다. 문자 열도 별도로 빈도와 고유 값을 확인한다.

```python
from lab import load_customers

df = load_customers()
print(df.shape)
print(df.dtypes)
print(df[["tenure_months", "monthly_fee", "support_calls"]].describe())
missing = df.isna().sum().sort_values(ascending=False)
duplicate_ids = df["customer_id"].duplicated().sum()
print(missing, "duplicate IDs:", duplicate_ids)
assert duplicate_ids == 0
assert set(df["churn"].unique()) == {0, 1}
assert (df["monthly_fee"] < 0).sum() == 1
```

결측 개수와 비율은 용도가 다르다. 비율은 표 크기가 달라도 비교할 수 있고 개수는 실제 영향을 보여준다. 작은 결측 비율이라도 타깃이 빠졌다면 학습 라벨을 임의로 만들면 안 된다.

## 2. 중복의 단위

전체 행이 같은 중복과 고객 ID 중복은 다른 검사다. 여러 달의 고객 기록이라면 ID가 반복되는 것은 정상일 수 있다. 이 책의 고객 자료는 독립 고객 한 행이라는 가정이므로 ID가 고유해야 한다.

같은 고객이 훈련·테스트에 함께 들어가면 평가가 낙관적일 수 있다. 실제 데이터의 단위가 반복 사람·장비·조직이면 그룹 기준 분할을 검토한다. 이 책에서 무작위 분할을 쓰는 이유는 가상 자료를 독립 행으로 만들었기 때문이다.

## 3. 불가능한 값과 드문 값

음수 요금이나 범위를 벗어난 이용 지수는 데이터 사전의 조건과 충돌한다. 큰 요금은 드물어 보여도 자동으로 잘못된 값이라고 할 수 없다. 생성 과정과 자료 정의를 확인하고 처리 이유를 남긴다.

이 책은 연습용으로 음수 요금·음수 이용 지수·큰 요금을 넣었다. 정해진 불가능 범위를 결측으로 바꾸는 예와, 극단값을 더 조사할 필요를 함께 보여준다. 실제 자료에서 동일한 숫자 기준을 그대로 적용하지 않는다.

## 4. 품질 기록을 행동으로 바꾸기

누락, 자료형 오류, 범위 위반, 중복과 타깃 불균형을 각각 기록한다. 필요한 처리를 “전체 결측 삭제”로 묶지 말고 열별 목적과 정보 손실을 고려한다. 모델을 비교할 때는 처리 방식과 영향을 같은 기준으로 유지한다.

자료 품질을 탐색하는 것과 평가 자료를 보고 모델 설정을 선택하는 것은 다르다. 분할 후 평가용 자료를 반복해서 보며 설정을 맞추면 평가가 개발 과정에 사용된다. 최종 테스트는 독립 확인용으로 남긴다.

## 연습과 해설

1. `info` 출력은 변수에 요약표를 반환하는가? **해설:** 일반적으로 정보를 출력하며 반환값은 `None`이다. 반환값이 필요하면 `dtypes`나 계산 결과를 사용한다.
2. ID 중복이 발견되면 항상 삭제해야 하는가? **해설:** 행의 단위를 먼저 확인한다. 반복 관측일 수 있으며 분할 기준도 바뀔 수 있다.

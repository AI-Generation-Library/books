# 용어 사전

| 용어 | 의미 | 구분할 것 |
| --- | --- | --- |
| 특성·입력 X | 예측에 사용할 설명 정보 | 타깃·ID·미래 정보 |
| 타깃 y | 예측할 값·라벨 | 예측 시점에 이미 아는 입력 |
| EDA | 구조·분포·관계를 탐색 | 원인·성능의 자동 증명 |
| 결측 | 값의 누락 표시 | 실제 0이라는 값 |
| 이상치 | 다른 값과 멀리 떨어진 관측 | 무조건 입력 오류 |
| 표준화 | 훈련 평균·표준편차 기준 변환 | 정규분포 생성 보장 |
| 원핫 | 범주별 표시 열 | 실제로 없는 수치 순서 |
| 층화 | 클래스 비율을 고려한 분할 | 연속값의 임의 라벨화 |
| Pipeline | 변환·모델의 순서 연결 | 모든 누수 자동 방지 |
| 과적합 | 훈련에 맞고 새 자료에서 약한 상태 | 모든 점수 차이의 유일 원인 |
| 검증 | 설정·후보를 비교하는 자료 | 마지막 독립 테스트 |
| 교차검증 | 폴드별 훈련·검증 반복 | 전체 변환을 미리 해도 된다는 뜻 |
| epoch | 훈련 자료를 한 번 학습하는 단위 | 업데이트 한 번 |
| 배치 | 한 업데이트의 샘플 묶음 | 전체 표본 수 |
| 손실 | 학습이 줄이려는 목적 값 | 모든 평가 지표와 동일 |
| 확률·점수 | 클래스 판단에 사용하는 연속 출력 | 확정 클래스·잘 보정된 위험의 보장 |
| 잔차 | 실제값−예측값 등 정의한 차이 | 제곱 오차와 동일한 값 |

정형 데이터의 기본 흐름은 문제 → 자료·품질 → 분할 → 훈련 변환 → 모델 → 검증 선택 → 고정 조건 테스트다. 실제 업무에서는 시간·그룹·자료 권한과 운영 조건을 더 검토한다.

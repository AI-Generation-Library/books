# 지표·출력층·손실 선택표

## 지표

| 목적 | 후보 | 입력·해석 |
| --- | --- | --- |
| 분류 전체 일치 | accuracy | 실제·예측 라벨, 불균형 주의 |
| 양성 예측의 정확성 | precision | 양성 라벨·0분모 확인 |
| 양성을 찾아낸 정도 | recall | FN·양성 라벨 확인 |
| 정밀도·재현율 결합 | F1 | 평균 방식·0분모 확인 |
| 순위 분리 | ROC AUC | 연속 점수·확률, 클래스 순서·분포 |
| 회귀 평균 절대 오차 | MAE | 원래 타깃 단위 |
| 회귀 큰 오차 강조 | RMSE | 원래 단위, 큰 오차 영향 |
| 기준 대비 설명 성능 | R² | 음수 가능, 무조건 0~1 아님 |

지표는 서로 다른 정의다. 검증에서 기준을 고르고 테스트에서는 고정 조건을 확인한다. 점수 최대화 인터페이스의 음수 손실에는 부호를 확인한다.

## 신경망의 일반적인 조합

| 타깃 | 출력 | 손실 | 예측 해석 |
| --- | --- | --- | --- |
| 이진 0·1 | 1 sigmoid | binary crossentropy | 확률·임계값 |
| 다중 클래스 정수 | k softmax | sparse categorical crossentropy | 클래스 열·argmax |
| 다중 클래스 원핫 | k softmax | categorical crossentropy | 클래스 열·argmax |
| 단일 연속값 | 1 linear | MSE 또는 MAE | 단위·역변환 |

logits 출력이면 손실 설정도 맞춘다. 위 표는 학습용 일반 조합이며 공식 시험의 지정 조건을 대신하지 않는다. 다중 출력·다중 라벨·특수 손실은 별도 문제다.

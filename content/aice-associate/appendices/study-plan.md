# 학습 체크리스트와 오답노트

기간은 독자의 가용 시간과 준비도에 따라 조정한다. 아래 네 묶음은 예시이며 합격 기간을 보장하지 않는다.

| 묶음 | 읽을 장 | 다음 단계로 갈 수행 |
| --- | --- | --- |
| 기초·분석 | 1~9 | CSV·형태·선택·집계·품질·그림 |
| 전처리 | 10~15 | 분할·훈련 통계·인코딩·일관성 |
| 모델·평가 | 16~25 | 기준·모델·출력·손실·지표·검증 |
| 통합·실전 | 26~30 | 새 커널 전체 실행·조건·저장·시간 |

## 수행 확인

- [ ] 타깃과 입력·식별자를 설명한다.
- [ ] 조건 선택의 경계와 행 대응을 확인한다.
- [ ] 결측·자료형·범위 위반·중복을 점검한다.
- [ ] 훈련·검증·테스트의 역할을 구분한다.
- [ ] 변환의 fit을 훈련 범위 안에서 수행한다.
- [ ] 새 범주·누락 열·열 순서를 확인한다.
- [ ] 클래스·확률·연속 예측을 구분한다.
- [ ] 지표의 단위·양성 클래스·평균 방식을 설명한다.
- [ ] 딥러닝의 라벨·출력·손실 조합을 맞춘다.
- [ ] 지정 변수·설정·파일·셀 규칙을 확인한다.
- [ ] 해설 없이 모의고사를 풀고 시간을 기록한다.
- [ ] 최신 공식 안내·사전 환경점검을 확인한다.

## 오답 기록

| 날짜·문제 | 실패 단계 | 잘못된 가정·코드 | 수정 이유·코드 | 다시 확인할 작은 사례 | 재확인 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

실행 오류와 요구조건 누락, 판단 오류를 구분한다. 해설 복사 후 성공을 독립 풀이 점수로 기록하지 않는다. 모의고사에는 완료·미완료·조건 누락과 분석·전처리·학습·검토 시간을 나눠 기록한다.

# 학습과 실습 기준

《AICE Associate 완전 정복》은 Python·pandas의 기초부터 정형 데이터 전처리, 머신러닝·딥러닝과 평가를 연결하는 수험 학습서다. 7부·30장, 장별 예제·연습 해설, 가상 데이터와 자체 모의고사 2회를 사용한다.

## 읽는 순서

처음 배우는 독자는 1~15장으로 자료·변환의 의미를 익히고 16~25장으로 모델·지표를 연습한다. 익숙한 독자는 26~27장의 통합 실습으로 부족한 단계를 찾은 뒤 돌아가도 된다. 28~30장에서는 요구조건·시간·오답을 확인한다.

각 장은 개념·판단 기준 → 실행 코드 → 결과의 의미·실수 → 연습과 해설로 이어진다. 코드 블록은 `examples`를 작업 위치로 사용한다. 파트별 노트북과 장 코드는 같은 소스를 공유한다.

## 공식 범위·보충 학습

공식 시험의 분석·전처리·AI 모델링 영역을 바탕으로 학습을 구성했다. Python 기초, 교차검증·Pipeline·추가 모델 비교는 이해를 돕는 보충 설명도 포함한다. 모든 장의 함수나 모델이 반드시 출제된다고 주장하지 않는다.

현재 확인한 안내와 실제 응시 회차의 조건이 다를 수 있다. 시험 방식·자료 사용·제출·환경은 [공식 Associate 안내](https://aice.study/info/aice/asso)와 [수험자 가이드](https://aice.study/certi/examGuide)를 확인한다. 책의 노트북은 학습용이며 공식 시험 화면을 대신하지 않는다.

## 자체 자료와 출처

분류·회귀 CSV와 문제·해설은 이 책을 위해 작성한 가상 자료다. 공개 기출·샘플을 복제하지 않았다. 가상 성능·자가 배점은 실제 시험의 점수·채점·합격 보장이 아니다. 모든 독자에게 같은 기간이 필요하다고 가정하지 않는다.

실습은 Python 3.12·CPU에서 고정 주요 의존성으로 확인한다. 버전·명령·검사 범위는 [검증 기록](verification.md), 공식 자료는 [참고 링크](references.md)에 남긴다. 다른 환경의 결과나 시험 서버에서의 동작은 그 환경에서 다시 확인한다.

사용자가 승인한 목차에 따라 Codex가 원고·자체 실습을 작성하고 book-generator가 원고 구조를 정리했다. 확인된 모델 식별자는 기록에 `null`로 두며 수정·검증 이력은 GitHub에서 관리한다. 원고·저자 작성 자료는 저장소의 CC0 정책을 따르고 외부 자료·라이브러리의 조건은 각 원출처에 따른다.

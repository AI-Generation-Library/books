# 실습 실행과 검증 기록

확인일: 2026-10-13. Python 3.12.14·Windows·CPU 환경에서 학습용 가상 정형 자료를 실행했다.

## 작성·범위

사용자가 승인한 7부·30장 목차에 따라 Codex가 원고·코드·자체 문제를 작성했다. book-generator의 API 없는 package 명령으로 구조를 정리한 뒤 노트북·목차 화면·실행 기록·최종 ZIP을 보완했다. 확인된 작성 모델 ID는 null이다. 생성기의 별도 OpenAI·Claude·Gemini API 호출은 없다. 이 기록은 Codex 대화 사용량이 없다는 뜻이 아니다.

## 실제 검사

- 승인 장 제목·번호·파트, Markdown 코드 블록·내부 링크·다운로드 형식을 검사했다.
- 3~29장의 Python 블록 27개를 장별 독립 프로세스로 실행했다. 원고의 코드와 동일한 블록을 사용했다.
- 모의고사 해설 스크립트 2개를 Q01~Q14 순서로 실행했다. 자체 28문항의 코드·형태·설정·출력 검사이며 실제 시험 채점이 아니다.
- 노트북 11개의 스키마를 검사했다. 파트별 완성 예제 7개·모의고사 해설 2개를 Jupyter 커널에서 실행했다. 연습 답안 2개는 독자가 작성할 학습지라 모델 풀이 실행 대상으로 세지 않았다.
- 데이터 경계 테스트 8개를 실행해 통과했다. 분할의 분리·행 대응, 훈련 통계 유지, 새 범주·누락 열과 자료형·예측 형태를 확인했다.
- 공식 자료의 확인 범위는 [참고 자료](references.md)에 기록했다.

주요 버전: NumPy 1.26.4, pandas 2.2.3, scikit-learn 1.6.1, Matplotlib 3.10.1, Seaborn 0.13.2, TensorFlow 2.20.0, Keras 3.10.0. 전체 설치 버전은 examples/requirements-lock.txt에 있다. 실행 중 라이브러리의 폐기 예정 API와 Windows 커널 관련 경고가 있었으며 실패는 없었다.

실행 요약은 examples/verification-results.json에 있다. 명령은 [실습 안내](../examples/README.md)를 따른다. 배포 노트북의 출력은 비워 두었으며 검증 시에는 실제 실행 결과를 확인했다.

## 해석의 범위

가상 자료의 모델 점수는 실제 고객·기업 성능이나 시험 합격을 증명하지 않는다. 그래프는 생성·실행을 확인했으며 모든 사람의 시각적 판정이나 공식 부분 점수 규칙을 확인한 것은 아니다. 전체 사람 편집·공식 기관 검수, 실제 시험 서버·감독·채점, 다른 OS·Colab·GPU와 모든 분기는 검증하지 않았다.

## 다운로드

원고 ZIP은 원고·승인 목차·메타데이터·자체 문제·데이터·코드·노트북·라이선스를 포함한다. ZIP 안에는 다운로드 ZIP을 다시 넣지 않으며 소개 화면의 자기 다운로드 버튼과 book.json.downloads만 생략한다. 장·실습 파일은 동일하다. 실습 ZIP에는 examples와 이 검증 기록·참고 링크를 포함한다.

책의 자체 원고·자료는 books의 CC0 정책을 따르고 외부 자료·라이브러리는 원출처 조건을 따른다.

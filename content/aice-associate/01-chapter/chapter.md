# 01장. AICE Associate 시험 이해하기

AICE Associate 준비의 첫 단계는 라이브러리 이름을 외우는 것이 아니라 주어진 데이터와 요구사항을 연결하는 것이다. 데이터를 읽고 구성·품질을 확인한 뒤 전처리, 모델 학습, 평가를 수행한다. 앞 단계가 잘못되면 뒤의 코드가 실행되어도 다른 문제를 풀고 있을 수 있다.

## 1. 공식 안내와 학습 구성을 구분하기

2026년 10월 13일 확인한 [공식 Associate 안내](https://aice.study/info/aice/asso)는 데이터 분석 30점, 데이터 전처리 30점, AI 모델링 40점의 영역을 제시한다. 전체 시험은 14문항·90분, 100점 중 80점 이상 합격이며 Python 실기와 제한적 오픈북 방식으로 안내되어 있다. 세부 조건은 응시 회차의 안내를 다시 확인한다.

이 책의 30장은 공식 문항 순서를 예언한 목록이 아니다. 공식 영역을 공부할 수 있도록 기초, 보충 설명과 통합 연습을 배치한 학습 순서다. 특정 알고리즘이 반드시 나온다거나 이 코드만 외우면 합격한다고 가정하지 않는다. 이 책의 데이터와 모의문항은 모두 자체 제작했다.

| 평가 영역 | 연습할 행동 | 연결 장 |
| --- | --- | --- |
| 데이터 분석 | 불러오기, 구성·품질 확인, 집계·시각화 | 5~9장 |
| 데이터 전처리 | 결측·이상치, 인코딩·스케일링, 분할 | 10~15장 |
| AI 모델링 | 머신러닝·딥러닝 학습, 평가·개선 | 16~25장 |
| 전체 흐름 | 요구사항을 따라 끝까지 실행 | 26~30장 |

## 2. 문항의 동사와 산출물을 찾기

“확인하라”, “제거하라”, “학습하라”, “저장하라”는 서로 다른 요구다. 타깃 열, 대상 행, 사용할 모델, 설정값, 변수명과 저장 파일을 표시한다. 모델 성능이 좋아도 지정 조건을 따르지 않았다면 요구를 충족했다고 볼 수 없다.

분류에서 `predict`로 얻은 클래스와 `predict_proba`의 확률은 다르다. 회귀의 연속값에 분류 지표를 적용하지 않는다. 문제를 읽을 때 입력·출력의 형태와 단위를 적으면 이런 실수를 줄일 수 있다.

## 3. 제한적 오픈북의 의미

오픈북을 모든 검색·도구·통신이 허용된다는 뜻으로 해석하지 않는다. [공식 수험자 가이드](https://aice.study/certi/examGuide)의 공통·Associate 안내와 해당 회차 공지를 확인한다. 이 책의 자료가 시험 중 허용되는지도 공식 규정에 따라 판단한다. 학습할 때 쓰는 AI 도구가 시험 중에도 허용된다고 가정하지 않는다.

확인한 Associate 유의사항에는 패키지·데이터 로딩 실패가 후속 문항에 영향을 줄 수 있다는 안내, 답안을 한 셀에 작성하는 안내와 문항의 파일명·확장자를 따르는 안내가 있다. 책의 다중 셀 노트북은 학습용이다. 실제 제출 방식은 시험 화면과 최신 가이드가 우선이다.

## 4. 시작과 끝을 모두 연습하기

처음에는 코드를 한 줄씩 이해하며 실행한다. 익숙해지면 빈 커널에서 데이터 로딩부터 다시 실행하고, 제한 시간을 두고 요구사항·출력·저장을 확인한다. 학습 환경이 시험 환경과 완전히 같다고 가정하지 말고 공식 사전 환경점검도 수행한다.

모의고사에서는 막힌 지점과 소요 시간을 기록한다. 로딩·형태·전처리 오류가 반복되면 모델 종류를 더 공부하기보다 그 단계의 독립 연습을 추가한다. 합격선과 학습용 자가점수는 서로 다른 평가이며 자체 문제의 점수로 실제 합격을 보장할 수 없다.

## 연습과 해설

1. “모델을 학습하고 정확도를 `score`에 저장”한다면 어떤 산출물이 필요한가? **해설:** 학습된 모델, 같은 전처리를 거친 평가 입력, 클래스 예측과 정확도 값이 필요하다. 변수명도 요구대로 맞춘다.
2. 공식 범위에 모델 개선이 있다는 이유로 모든 복잡한 알고리즘을 외워야 하는가? **해설:** 기본 흐름과 요구조건을 먼저 익히고, 보충 주제는 시간과 준비도에 맞게 공부한다.

다음 장에서 자신의 준비도를 바탕으로 실습과 복습 순서를 정한다.
